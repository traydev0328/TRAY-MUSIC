# TRAY BLACK RAIN — 모바일·PC 3D FPS (싱글 + 멀티 협동)

폭우가 쏟아지는 해 질 녘 항만 물류 기지에서 전투 안드로이드·공격 드론 웨이브를 막아 내는 웹 기반 1인칭 슈팅 게임입니다.
설치 없이 휴대폰 브라우저(Chrome/Samsung Internet/Safari)와 PC 브라우저에서 실행됩니다.

- **싱글 작전**: 혼자서 웨이브 방어
- **멀티 협동**: 최대 4명. 방장 기기가 서버 역할을 하는 P2P(WebRTC) 방식이라 서버 비용이 없습니다

## 공개 주소 만들기 (GitHub Pages, 무료)

저장소가 공개(public)라서 무료로 호스팅됩니다. 최초 1회만 설정하면 이후에는 `main` 에 반영될 때마다 자동 배포됩니다.

1. GitHub 저장소 → **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택
2. 이 브랜치를 `main` 에 병합 (PR 생성 후 Merge)
3. **Actions** 탭에서 `Deploy TRAY BLACK RAIN (GitHub Pages)` 가 초록 체크가 되면 완료
4. 주소: `https://traydev0328.github.io/TRAY-MUSIC/`

> claude.ai 미리보기(Artifact) 페이지에서는 보안 정책상 실시간 통신이 막혀 **멀티플레이가 동작하지 않습니다.** 멀티는 GitHub Pages 주소에서 이용하세요.

## 멀티 협동 사용법

1. 방장: 메인 메뉴 → **멀티 협동** → 호출명 입력 → **방 만들기** → 5자리 방 코드 또는 **초대 링크 복사**를 친구에게 전달
2. 참가자: 초대 링크를 열거나 **멀티 협동** → 방 코드 입력 → **참가**
3. 방장이 **출격**을 누르면 모두 시작합니다 (진행 중인 작전에도 참가 가능)

| 규칙 | 내용 |
|---|---|
| 판정 | 적 AI·웨이브·점수·픽업·폭발물은 방장이 계산해 초당 20회 동기화 |
| 인원 보정 | 인원이 늘면 적 수가 1인 기준 × (1 + 0.6 × 추가 인원) 으로 증가 |
| 사망 | 전사하면 아군을 관전하고, 웨이브가 끝나면 재투입 |
| 패배 | 모든 대원이 전사하면 분대 전멸 |

알아둘 점:
- **방장이 앱을 닫거나 화면을 끄면 모두의 게임이 멈춥니다** (브라우저가 백그라운드 탭을 정지시키기 때문). 게임 중 화면 꺼짐 방지(Wake Lock)를 요청합니다.
- 연결 중개는 무료 공개 신호 서버(PeerJS)를 사용합니다. **일부 모바일 데이터망(대칭형 NAT)에서는 P2P 연결이 실패할 수 있습니다.** 이를 완전히 해결하려면 TURN 중계 서버가 필요합니다(대부분 유료).
- 협동 모드라 각자 자기 이동을 신뢰 기반으로 보냅니다. 치트 방지는 약합니다.

## 로컬에서 실행

ES 모듈을 쓰기 때문에 `index.html` 을 더블클릭하면 동작하지 않습니다. 작은 로컬 웹 서버가 필요합니다.

```powershell
# Windows 11 PowerShell — tray-fps 폴더에서
cd tray-fps
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

같은 PC 에서 멀티를 시험하려면 `http://localhost:8080/?net=local` 을 탭 두 개로 열면 됩니다 (인터넷 없이 탭끼리 통신).
