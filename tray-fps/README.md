# TRAY BLACK RAIN — 모바일 3D FPS (싱글 전용)

폭우가 쏟아지는 해 질 녘 항만 물류 기지에서 전투 안드로이드·공격 드론 웨이브를 막아 내는 웹 기반 1인칭 슈팅 게임입니다.
설치 없이 휴대폰 브라우저(Chrome/Samsung Internet/Safari)에서 실행되며, PC(마우스+키보드)도 지원합니다.

## 실행 방법

ES 모듈을 쓰기 때문에 `index.html` 을 더블클릭하면 동작하지 않습니다. 작은 로컬 웹 서버가 필요합니다.

```powershell
# Windows 11 PowerShell — tray-fps 폴더에서
cd tray-fps
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

휴대폰에서 테스트하려면 PC 와 같은 Wi-Fi 에 연결한 뒤 `http://<PC의 IP>:8080` 으로 접속합니다. (PC IP 확인: `ipconfig` → IPv4 주소)
Three.js 는 jsDelivr CDN(`three@0.160.0`)에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

| 동작 | 휴대폰 | PC |
|---|---|---|
| 이동 | 왼쪽 화면 드래그(가상 조이스틱) | WASD |
| 질주 | 조이스틱을 위쪽 바깥까지 밀기 | Shift |
| 시점 | 오른쪽 화면 드래그 | 마우스(클릭 시 포인터 잠금) |
| 사격 | 오른쪽 큰 버튼 / 왼쪽 보조 버튼 (누른 채 드래그하면 조준하며 사격) | 좌클릭 |
| 정조준 | `조준` 버튼(토글) | 우클릭(토글) |
| 점프 / 앉기 / 재장전 | 각 버튼 | Space / C / R |
| 무기 교체 | 오른쪽 위 탄약 표시 터치 | Q, 1, 2, 휠 |
| 일시정지 | ⏸ 버튼 | Esc |

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | HUD·메뉴·터치 버튼 마크업과 스타일, import map |
| `src/main.js` | 부트스트랩, 게임 루프, 웨이브, 픽업, HUD, 메뉴/설정, 동적 해상도 |
| `src/world.js` | 맵(창고·컨테이너 야드·크레인·사무동), 조명, 절차적 하늘/구름/번개, GPU 비, 젖은 노면 셰이더, AABB 충돌, A* 길찾기 격자 |
| `src/textures.js` | 이미지 파일 없이 알베도·노멀·ORM 맵을 생성하는 절차적 PBR 텍스처 |
| `src/player.js` | 캡슐 충돌 이동, 점프/앉기/질주, 반동 회복, 카메라 흔들림, 체력 재생 |
| `src/weapons.js` | 1인칭 뷰모델(소총·산탄총·팔), 히트스캔 사격, 탄 퍼짐, 재장전/교체/펌프 애니메이션 |
| `src/enemies.js` | 워든(안드로이드)·호넷(드론)·불워크(중장갑) AI, 사격 토큰, 부품 분리 사망 연출 |
| `src/effects.js` | GPU 파티클(불꽃·연기·섬광), 탄흔 데칼, 예광탄, 탄피, 파편 물리 |
| `src/post.js` | 후처리: 블룸, ACES 톤매핑, 색 보정·비네트·색수차·필름 그레인, FXAA, (울트라) GTAO |
| `src/audio.js` | WebAudio 실시간 합성: 총성·야외 잔향·빗소리·천둥·발소리·드론 로터 |
| `src/config.js` | 품질 프리셋, 설정·최고 기록 저장(localStorage) |

## 그래픽 품질 프리셋

| 프리셋 | 렌더 배율 상한 | 그림자 | 블룸 | GTAO | 빗줄기 수 |
|---|---|---|---|---|---|
| 낮음 | 0.85x | 끔 | 끔 | 끔 | 1,200 |
| 중간(휴대폰 기본) | 1.25x | 1024 | 켬 | 끔 | 2,400 |
| 높음(PC 기본) | 1.75x | 2048 | 켬 | 끔 | 3,600 |
| 울트라 | 2.25x | 4096 | 켬 | 켬 | 5,200 |

동적 해상도가 켜져 있으면 평균 프레임 시간이 21ms(약 48fps)를 넘을 때 렌더 해상도를 단계적으로 낮춥니다.

## 현재 상태 (정직한 표시)

| 항목 | 상태 |
|---|---|
| 게임 루프·웨이브·적 AI·사격·픽업·게임 오버 | 구현 · 헤드리스 Chromium 자동 시뮬레이션으로 웨이브 1→3 진행, 처치, 사망까지 확인 |
| 모바일 터치 조작(조이스틱·시점·사격 버튼) | 구현 · Chromium 터치 에뮬레이션으로 이동/회전/사격 확인 · **실기기 미검증** |
| 그래픽(PBR·그림자·젖은 노면·비·번개·후처리) | 구현 · 소프트웨어 렌더러(SwiftShader) 스크린샷으로 확인 |
| 실제 휴대폰 프레임레이트 | **미측정** — 테스트 환경에 GPU 가 없어 측정 불가. 실기기에서 설정 → FPS 표시로 확인 필요 |
| 사운드 | 구현 · 헤드리스 환경 특성상 청취 검증은 안 됨 |

한계: 모든 모델은 기본 도형 조합 + 절차적 텍스처로 만들었습니다. 포토스캔 에셋·스켈레탈 애니메이션을 쓰는 상용 콘솔 게임 수준의 사실감은 아니며, 이를 원하면 glTF 에셋(예: Poly Haven 의 CC0 텍스처/모델)을 추가하는 단계가 필요합니다.
